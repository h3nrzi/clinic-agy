## Final implementation decisions
Role-aware navigation uses a small presentation-only Zustand store, with each role returning to its overview on a demo role change. It does not alter permission or financial repositories. Reception tables become labeled rows on mobile; finance tables retain horizontal scrolling. Reusable dialog focus behavior handles Escape, focus cycling and return focus, including stacked dialogs. Doctor summary reuses the existing compensation engine. Authentication is an explicitly isolated identity/consent/OTP demonstration, accessible from the account panel; it does not masquerade as a backend-authenticated session. No dependencies were added.

Existing stack inspection found no installed Radix packages, so the implementation retained existing dialogs and added focused keyboard behavior rather than introducing a new library.
