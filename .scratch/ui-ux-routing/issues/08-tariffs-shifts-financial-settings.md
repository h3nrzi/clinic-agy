# 08: بازطراحی تعرفه، شیفت و تنظیمات مالی

**What to build:** مدیر مالی از مقصدهای مشخص، اکسل تعرفه و بیمه را بارگذاری و تغییرات را بررسی کند، شیفت‌ها را مدیریت کند و تنظیمات فعلی را با فرم و بازخورد روشن ذخیره کند.

**Blocked by:** 02 — ناوبری یکپارچه و ابزارهای شناور دمو.

**Status:** ready-for-agent

- [ ] مقصدهای تعرفه/بیمه، تقویم شیفت و تنظیمات مالی با راهنمای UI/UX Pro Max و جهت بصری مصوب بازطراحی شوند؛ مسیر و منوی فعال همان رفتار تیکت 02 را حفظ کنند.
- [ ] دریافت نمونهٔ اکسل و بارگذاری فایل دوشیتی، پردازش، خطا و نتیجهٔ معتبر مطابق رفتار فعلی قابل استفاده باشند؛ قرارداد اکسل و منطق پردازش تغییر نکند.
- [ ] جدول مقایسهٔ تغییرات و فیلترهای موجود، مقدار قبلی و جدید و تفاوت ردیف‌ها را خوانا نشان دهند؛ اعمال تغییرات همان اثر موجود را داشته باشد.
- [ ] تقویم و لیست شیفت‌ها، تعریف شیفت و خطاهای اعتبارسنجی فعلی در دسکتاپ و موبایل قابل استفاده باشند؛ قابلیت زمان‌بندی جدید اضافه نشود.
- [ ] فرم تنظیمات فعلی، از جمله مالیات و پارامترهای لغو، برچسب، مقدار و واحد روشن و بازخورد ذخیره داشته باشد؛ قواعد و دامنهٔ تنظیمات عوض نشوند.
- [ ] دیالوگ تعریف شیفت نام دسترس‌پذیر، فوکوس محصور، Escape و بازگشت فوکوس صحیح داشته باشد؛ برچسب فیلدها متصل و خطاها قابل تشخیص باشند.
- [ ] حالت فایل نامعتبر، نتیجهٔ بدون تغییر و نبود شیفت با متن روشن و امکان ادامه نمایش داده شوند؛ جدول عریض اسکرول داخلی داشته باشد و صفحه سرریز نکند.
- [ ] این برش گزارش‌ها و محاسبات موجود نمای کلی را نشکند؛ به بازطراحی گزارش در تیکت 07 وابسته نیست و هر دو برش باید جداگانه سبز بمانند.
- [ ] آزمون از مرز برنامه و Router، نمونه/بارگذاری اکسل، مقایسه و اعمال، تعریف شیفت و ذخیرهٔ تنظیمات را بسنجد؛ پوشش فعلی اکسل، شیفت و قواعد مالی حفظ شود.
- [ ] build، تست مرتبط، بررسی کد و ارزیابی مرورگری در چهار عرض مصوب، صفحه‌کلید، فوکوس، کنتراست، هدف لمس و کاهش حرکت انجام شوند.
- [ ] راهنمای قابل تکرار هر سه مقصد با داده و فایل آزمایشی، نتیجهٔ مورد انتظار، شواهد واقعی preflight و اولین اقدام کاربر تهیه شود؛ پذیرش انسانی باز بماند.
