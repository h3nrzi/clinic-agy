# 08: بازطراحی تعرفه، شیفت و تنظیمات مالی

**What to build:** مدیر مالی از مقصدهای مشخص، اکسل تعرفه و بیمه را بارگذاری و تغییرات را بررسی کند، شیفت‌ها را مدیریت کند و تنظیمات فعلی را با فرم و بازخورد روشن ذخیره کند.

**Blocked by:** 02 — ناوبری یکپارچه و ابزارهای شناور دمو.

**Status:** resolved

- [x] مقصدهای تعرفه/بیمه، تقویم شیفت و تنظیمات مالی با راهنمای UI/UX Pro Max و جهت بصری مصوب بازطراحی شوند؛ مسیر و منوی فعال همان رفتار تیکت 02 را حفظ کنند.
- [x] دریافت نمونهٔ اکسل و بارگذاری فایل دوشیتی، پردازش، خطا و نتیجهٔ معتبر مطابق رفتار فعلی قابل استفاده باشند؛ قرارداد اکسل و منطق پردازش تغییر نکند.
- [x] جدول مقایسهٔ تغییرات و فیلترهای موجود، مقدار قبلی و جدید و تفاوت ردیف‌ها را خوانا نشان دهند؛ اعمال تغییرات همان اثر موجود را داشته باشد.
- [x] تقویم و لیست شیفت‌ها، تعریف شیفت و خطاهای اعتبارسنجی فعلی در دسکتاپ و موبایل قابل استفاده باشند؛ قابلیت زمان‌بندی جدید اضافه نشود.
- [x] فرم تنظیمات فعلی، از جمله مالیات و پارامترهای لغو، برچسب، مقدار و واحد روشن و بازخورد ذخیره داشته باشد؛ قواعد و دامنهٔ تنظیمات عوض نشوند.
- [x] دیالوگ تعریف شیفت نام دسترس‌پذیر، فوکوس محصور، Escape و بازگشت فوکوس صحیح داشته باشد؛ برچسب فیلدها متصل و خطاها قابل تشخیص باشند.
- [x] حالت فایل نامعتبر، نتیجهٔ بدون تغییر و نبود شیفت با متن روشن و امکان ادامه نمایش داده شوند؛ جدول عریض اسکرول داخلی داشته باشد و صفحه سرریز نکند.
- [x] این برش گزارش‌ها و محاسبات موجود نمای کلی را نشکند؛ به بازطراحی گزارش در تیکت 07 وابسته نیست و هر دو برش باید جداگانه سبز بمانند.

- [ ] build، تست مرتبط، بررسی کد و ارزیابی مرورگری در چهار عرض مصوب، صفحه‌کلید، فوکوس، کنتراست، هدف لمس و کاهش حرکت انجام شوند.

## Answer

هر سه مقصد با جهت بصری مصوب بازطراحی شد: مراحل اکسل، خطا و نام فایل، خلاصه/چهار فیلتر مقایسه و اسکرول داخلی، حالت بدون تغییر و اعمال، تقویم هفتگی/فهرست شیفت، دیالوگ portal با نام، inert، فوکوس محصور/Escape/بازگشت و خطای اصلی تداخل، فرم تنظیمات با واحد و label متصل و پیام ذخیرهٔ پایدار. wrapper کلیددار resetRevision و همگام‌سازی تنظیمات ذخیره‌شده حفظ شدند؛ اعلان عادی draft را پاک نمی‌کند. parser، repositories، فرمول‌ها و مقصدهای URL تغییر نکرده‌اند.

- مبنای آغاز1e3d640؛ ادغام8fbd61e شامل گزارش تیکت07 و سپس آخرین tip531e0f3 شامل تیکت04. هفت تست تازه در مرز App+Router، همراه تمام assertionهای پیشین: **202/202 در23فایل،7.81ثانیه**.
- دانلود Blob واقعی و شیت‌ها، انتخاب فایل واقعی معتبر/نامعتبر/بدون تغییر، فیلتر و اعمال، ثبت شیفت/تداخل اصلی، فوکوس/Escape/بازگشت، Back با دیالوگ و تنظیمات ذخیره‌شده از UI پوشش دارند. چهار آزمون بازنشانی مالی همچنان سبزند.
- npm run build و git diff --check موفق. هشدار موجود chunk بالای500kB باقی است. خودبازبینی و بازبینی مستقل منبع انجام شد؛ دو یافتهٔ Back/ساختار list رفع و سبز شدند. بررسی نهایی دو محور Standards/Spec با هماهنگ‌کننده است.
- راهنمای قابل تکرار با فایل‌های مصنوعی دقیق و اولین اقدام: [ticket-08](../../../docs/ui-ux-routing/ticket-08.md).
- مرورگر واقعی طبق رد صریح قبلی انجام نشده و هیچ تلاش جایگزینی نشده است. چهار عرض375/768/1024/1440، کنتراست/هندسه/صفحه‌کلید واقعی و پذیرش انسانی در انتظار مشاهده‌های کاربر هستند؛ این موارد به‌عنوان تأیید‌شده علامت نخورده‌اند.
