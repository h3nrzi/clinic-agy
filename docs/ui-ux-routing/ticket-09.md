## شواهد واقعی پیش‌پرواز — ۲۰۲۶-۱۱-۰۱

- مبنا و آخرین integration: `218c69a` شامل۰۱–۰۸، شاخه `codex/ui-ux-09`. `npm ci` برای worktree تازه اجرا شد. dependency یا رفتار backend جدید اضافه نشد.
- مرز مصوب همهٔ تست‌های جدید: برنامهٔ کامل + Router. پایگاه داده/حساب فقط setup است؛ assertions از نقش‌ها و نام‌های معنایی UI، متن، URL، disabled و مقدار کنترل‌اند. تغییر حساب در جریان‌ها از logout/login واقعی است. فقط randomness کد رهگیری به‌عنوان boundary برای جلوگیری از برخورد تصادفی با seed کنترل شده است.
- tracer دور تازه ابتدا تا پزشک پیش رفت ولی selector نامعتبر row داشت؛ اصلاح تست از جستجوی عمومی کارتابل استفاده کرد و جریان سبز شد. این شکست selector، نقص محصول گزارش نشده است. تعرفه، propagation و guard/account-isolation روی اتصال موجود سبز شدند؛ بدون ادعای red ساختگی، رفتار موجود را تثبیت می‌کنند.
- چرخه واقعی قرمز/سبز محصول: تست وضعیت پزشک بر نبود «در انتظار پرداخت» شکست خورد؛ map کامل و typed وضعیت‌های فعلی، enum انگلیسی را به فارسی تبدیل کرد. محصول هیچ قاعدهٔ نوبت/صلاحیت/مالی را عوض نکرد.
- چرخه واقعی قرمز/سبز معنا: تست اتصال شیفت/مرخصی با نبود article نام‌دار قرمز شد؛ همان کارت‌های پزشک به article با نام روز/بازه تبدیل شدند. assertions مالی و تصمیم مرخصی همان مقادیر ماندند؛ هیچ ancestor/CSS selector جدیدی لازم نیست.
- اجرای متمرکز جدید + E2E قبلی + پذیرش: **۱۸/۱۸ در۳فایل**،۴٫۱۴ثانیه. پس از افزودن کنترل randomness، اجرای کامل نهایی **۲۴۰/۲۴۰ در۲۵فایل**، **۱۱٫۴۶ثانیه** موفق شد. هشدارهای قدیمی `act` از fixture/subscription وجود دارند؛ شکست نداریم. این‌ها jsdom هستند.
- `npm run build`: TypeScript و Vite موفق؛ JS **۱٬۰۲۸٫۵۰kB**، gzip **۳۰۵٫۸۰kB**؛ CSS۱۱۹٫۳۸kB، gzip۲۲٫۰۷kB. هشدار موجود chunk بیش از۵۰۰kB باقی است.
- `git diff --check` برای working diff موفق بود. بررسی range نسبت به `0eaa111a36af2ca66eb91bf632386ff0bd3c9645...HEAD` ابتدا EOF از پیش commit‌شدهٔ `consultationAccess.ts` را پیدا کرد؛ حذف خط خالی در این تیکت انجام شد پس از commit، هر دو دستور `git diff --check 0eaa111a36af2ca66eb91bf632386ff0bd3c9645...HEAD` و `git diff --check` با خروجی خالی موفق شدند. آخرین integration بدون تغییر تازه در شاخه۰۹ موجود است.
- خودبازبینی منبع انجام شد: permission پیش از render، guard مشترک، remount حساب/نوبت، مالکیت منبع و قواعد مالی/بیمه/لغو/repositories تغییر نکرده‌اند؛ تغییر محصول فقط وضعیت فارسی، semantic article، متن پذیرش و EOF است. والد pointers منبع را مرور و ancestor selector جدید را رد کرد؛ selectorها به نام معنایی اصلاح شدند. بازبینی مستقل نهایی دو محور Standards/Spec توسط هماهنگ‌کننده **پس از ادغام۰۹** انجام می‌شود؛ تکمیل آن در این checkpoint ادعا نشده است.
- entrypointهای تاریخی به README جاری اشاره دارند و سابقهٔ evidence حفظ شده است. `design-system/clinic-agy/IMPLEMENTATION.md` با حساب/URL/نشست و حالت نهایی همگام شد. خروجی cache ابزار skill در commit نیست.

## موارد مسدود/در انتظار

- دسترسی مرورگر localhost قبلاً صریحاً رد شده بود؛ در۰۹ هیچ مرورگر، retry، host جایگزین یا workaround استفاده نشد.
- عرض‌های۳۷۵/۷۶۸/۱۰۲۴/۱۴۴۰، هندسه/اسکرول واقعی، اهداف لمس، کنتراست اندازه‌گیری‌شده، keyboard/focus واقعی، Escape چندلایه در مرورگر، reduced motion و نمایش native beforeunload **بررسی واقعی نشده‌اند**. synthetic event و hook tests جای آن‌ها نیستند.
- زمان اجرای تست ماشینی شاهد رزرو زیر۳دقیقه توسط انسان یا پذیرش کیفیت UI نیست. پذیرش انسانی تا گزارش کاربر معلق است و مانع تحویل پیاده‌سازی تکمیل‌شده نیست.
- parser/repository تعرفه رفتار قبلی تطبیق نام/کد قواعد تکمیلی را حفظ دارند؛ محدودیت re-upload نمونه در [۰۸](ticket-08.md) ثبت است. بازگشایی اضطراری تسویه بدهی نیست. هیچ freeze بیمه یا قاعدهٔ زمانی تازه ادعا نمی‌شود.
- استقرار/سرویس واقعی انجام نشده؛ میزبانی آینده برای deep-linkهای SPA به fallback `index.html` نیاز دارد.

برای هر مشاهده، checkpoint، حساب، URL، عرض، فایل/داده، اقدام، انتظار و نتیجه را ثبت کنید. هر راهنمای۰۱–۰۸ همچنان checkpoint مستقل خود را دارد؛ این تیکت جای آن‌ها را نگرفته است.
