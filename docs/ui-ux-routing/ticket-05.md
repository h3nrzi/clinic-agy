# ارزیابی تیکت 05: میز پذیرش و درخواست‌های مرخصی

پیاده‌سازی آمادهٔ ارزیابی است. پذیرش انسانی و مشاهدهٔ مرورگر واقعی تا گزارش کاربر **در انتظار** هستند.

## اولین اقدام شما

`npm run dev` را در پروژه اجرا و [پذیرش تهران](http://localhost:5173/secretary/tehran) را باز کنید. با «حساب منشی تهران»، «استفاده از مشخصات آزمایشی»، رضایت و کد `123456` وارد شوید. نام منشی تهران، مقصد پذیرش و فیلتر انتخاب‌شدهٔ «شعبه تهران + آنلاین» باید دیده شوند. برای شروع از نمونهٔ پاک، ابزارهای دمو را باز و بازنشانی را تأیید کنید؛ این کار داده‌های نمایشی ثبت‌شده را بازنشانی می‌کند.

## شواهد واقعی preflight — ۲۰۲۶-۱۱-۰۱

- مبنا `195390b` و شاخه `codex/ui-ux-05`؛ مرز مصوب آزمون، برنامهٔ کامل + Router است. داده‌ها نمونهٔ موجود و fixtureهای صریح حساب‌اند؛ backend یا فایل ورودی جدید وجود ندارد.
- راهنمای UI/UX Pro Max با جستجوی `keyboard focus modal`، فوکوس واضح و پوشیده‌نشدن فوکوس را برگرداند. override مصوب عملیات متراکم/سفید/خاکستری/teal اعمال شد. خوانایی کارت موبایل، اهداف لمس، وضعیت انتخاب، متن بلند و فرم اسکرول‌پذیر از کد بررسی شدند؛ این‌ها شاهد اندازه‌گیری مرورگر نیستند.
- چرخهٔ نخست: دو تست حساب/جستجو به‌علت نبود `aria-pressed` قرمز، چهار تست موجود/لایه سبز؛ پس از برچسب، انتخاب صریح و reset، شش تست سبز شدند. پوشش بعدی شامل تأیید و رد مرخصی از مقصد واقعی هر حساب است.
- بررسی مستقل منبع توسط هماهنگ‌کننده، تداخل دو مالک scroll lock را پیدا کرد: تست کامل باز/بسته‌شدن ابزار دمو باید `overflow:auto` را برمی‌گرداند اما `hidden` می‌ماند. این رگرسیون قرمز بازتولید شد؛ حذف فقط تغییر overflow از `useWorkspaceOverlay` و مالکیت واحد در `useDialogFocus` آن را سبز کرد. inert پوسته و ترتیب بازگشت فوکوس حفظ شدند. آزمون لایهٔ مدرک نیز Tab/Shift+Tab، Escape و برگشت فوکوس و حفظ lock تا بستن کشو را بررسی می‌کند.
- عنوان نادرست فریز و برچسب سناریوی AC از دیالوگ بیمه حذف شدند. سه selector متن در آزمون سراسری با عنوان جدید تطبیق یافتند؛ assertionهای مالی، قفل، تسویه، ممیزی و محرمانگی قبلی حذف یا ضعیف نشدند. repositories و محاسبات تغییر نکردند.
- اجرای نهایی `npm test -- --reporter=dot`: **۱۷۷/۱۷۷ موفق در۲۰ فایل**، مدت **۶٫۲۷ ثانیه**. مجموعهٔ پذیرش شامل **۹/۹** تست است؛ هشدارهای act مربوط به fixtureهای قدیمی باقی‌اند و شکست وجود ندارد. `npm run build`: TypeScript و Vite موفق، JS **۱٬۰۲۱٫۸۷kB**، gzip **۳۰۲٫۲۶kB**؛ هشدار موجود chunk بزرگ باقی است. `git diff --check` موفق است. بررسی منبع توسط پیاده‌ساز و بررسی متمرکز هماهنگ‌کننده انجام شده؛ رگرسیون scroll اصلاح شد. بررسی مستقل نهایی دو محور standards/spec پس از ادغام همهٔ تیکت‌ها با هماهنگ‌کننده است.
- مرورگر واقعی انجام نشده: دسترسی localhost پیش‌تر صریحاً رد شده است؛ تلاش جایگزین صورت نگرفت. شواهد واقعی چهار عرض، هندسه/کنتراست، صفحه‌کلید بومی، کاهش حرکت و پذیرش انسانی همچنان باز هستند. jsdom اثبات کیفیت بصری نیست.
